# Python Bookstore

A simple Python-based bookstore application. This repository contains the source code and resources for a bookstore app implemented in Python. It includes modules for managing inventory, books, and basic operations such as adding, removing, searching, and purchasing books.

## Features

- Add, update, and remove books from inventory
- Search books by title, author, or ISBN
- Simple purchase flow with stock decrement
- CLI and/or simple script-based usage (depending on included modules)

## Requirements

- Python 3.8+
- (Optional) Virtual environment tool such as venv or virtualenv

## Installation

1. Clone the repository:

   git clone https://github.com/divinangelo357/Python_Bookstore.git
   cd Python_Bookstore

2. Create and activate a virtual environment (recommended):

   python -m venv venv
   # On macOS/Linux
   source venv/bin/activate
   # On Windows (PowerShell)
   .\venv\Scripts\Activate.ps1

3. Install dependencies (if a requirements.txt file exists):

   pip install -r requirements.txt

## Usage

- Inspect the repository for entry-point scripts (for example `main.py` or a `cli.py`).
- Run the main script:

  python main.py

- Or import modules into a Python REPL or other scripts for programmatic usage.

## Tests

If the repository includes tests, run them with pytest:

   pip install pytest
   pytest
